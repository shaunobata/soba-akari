# 手打そば 燈り 公式サイト

WordPress（クラシックテーマ）で作る公式サイトのコード。仕様は同じフォルダの設計書3点（要件定義書・基本設計書・詳細設計書）による。

## 構成

```text
wp-content/
├── mu-plugins/
│   ├── akari-core.php        読み込みだけ
│   └── akari-core/           データの定義（投稿タイプ・入力欄・権限・共通設定・SEO・構造化データ・画像・セキュリティ・初期設定）
└── themes/akari/             表示（テンプレート・部品・CSS・JS）。ビルドツールなし
```

テーマを戻しても月替わり・設定値・権限が消えないよう、データの定義は mu-plugin に分けている（詳細設計書2章）。

## 導入（本番・ローカル共通）

1. WordPress（PHP 8.3以上）を入れ、`wp-content/mu-plugins/` と `wp-content/themes/akari/` をこのリポジトリのとおりに置く
2. 外観 → テーマで「akari」を有効にする
3. 管理者で管理画面を開くと、初回だけ次を自動で作る（`akari-core/setup.php`）
   - 固定ページ：トップ・季節のおすすめ・お品書き・夜の楽しみ方とコース（下書き）・店舗情報・お知らせ・こだわり・口コミのお願い・プライバシーポリシー
   - ホームページ／投稿ページの指定、パーマリンク `/news/%post_id%/`、カテゴリーベース `news/category`
   - カテゴリ（メニュー・季節・休業）、タイムゾーン「東京」、1ページ10件
4. 管理画面「店舗情報」で【要確認】の値（電話・受付時間・L.O.・ネット予約URL・地図・GTMのIDなど）を入れる。空の項目はページにも構造化データにも出ない
5. 「コース」「お品書き」を入れ、トップ・各ページの入力欄に写真を入れる
6. 店主のユーザーを作り、権限グループ「店主（燈り）」にする
7. プラグイン Two Factor・Limit Login Attempts Reloaded・UpdraftPlus を入れる（詳細設計書8章）
8. `wp-config.php` に詳細設計書10.1の定数（`DISALLOW_FILE_EDIT` など）を入れる

## 公開前に残っていること

- 【要確認】の値（電話番号・電話受付時間・L.O.・カードのブランド・領収書・お通し・郵便番号・地図・口コミ投稿URL・食べログURL）
- D1（コース）・D3（貸切）・D8（キャッチコピー）の確定と入力
- 写真（メインビジュアル・おすすめ3品・席・道順など）。写真がない枠は文字だけで出る
- ロゴデータ（今は灯りのアイコン＋文字のロゴ）
- 見出しのWebフォント（A案）：`assets/fonts/heading-subset.woff2` を置くと自動で読み込む。置かない間はシステムの明朝体
- 色の16進値・書体の最終値（関門3b）。`assets/css/main.css` 冒頭のトークンを差し替える
- テーマの screenshot.png

## 設計書との違い・補足

- **昼も夜も見せる（2026-10-30の方針変更）**：トップのメインビジュアル直後に「昼も、夜も」（昼の燈り・夜の燈り）を置く。昼と夜のカードは同じ大きさ（2026-10-31 店主依頼）。旧セクション8（昼の燈り）はここへまとめた。メインビジュアルの営業時間も昼・夜を分けて並べる。トップのセクション順を変えるため、要件定義書10章「変更の扱い」で店主の了承を取る
- **キャッチコピーの初期値**：「昼は手打ち蕎麦、夜は蕎麦屋で一献。」（D8の仮。要件定義書の3案はいずれも夜寄りのため）
- **こだわりページ（/about/）**：作る（公開）。蕎麦粉 → 昼の蕎麦・夜の締めの蕎麦 → 店主の想い（インタビュー後に入力。空なら出さない）→ 締め
- **季節のおすすめ（/seasonal/、2026-10-31 店主依頼で新設）**：今月の月替わりと、季節限定を出す。季節限定は新しい投稿タイプ（`akari_seasonal`）で、掲載の始まりの月〜終わりの月（空なら下書きに戻すまで）の間だけ出る。店主も追加・編集できる（ロールの版を2に上げた）。トップの月替わりは「昼も、夜も」と同じ夜の地にし、ここへリンク
- **ナビの順（2026-10-31 店主依頼）**：季節のおすすめ → お品書き → こだわり → 店舗情報 → お知らせ。Instagramはヘッダー右上（電話・メニューと同じアイコン＋文字）とフッター（同じアイコン）
- **トップの並び（2026-10-31 店主依頼）**：今月の月替わりをメインビジュアルの次へ。お客様の声は削除（入力欄・テンプレートも削除）
- **メインビジュアルのロゴ**：トップの入力欄「1 メインビジュアルのロゴ」に入れると、H1の店名がロゴ画像になる（代替テキストは店名）。今のローカルは、スクリーンショットから背景を抜いた仮の画像。本番用は背景が透明なPNG（幅360px以上）かSVGをもらう
- **夜の楽しみ方（/night/）を取り下げ（2026-10-31 店主依頼）**：コース（D1）が決まるまで下書き。テンプレート `page-night.php` は残す。公開すると、ナビ・各ページのリンク・トップの夜のコースが自動で戻る
- **宴会・貸切のページ（/party/）を廃止（2026-10-31 店主依頼）**：トップの「宴会・会食・貸切」（`#party`。ヒーローからアンカーリンク）と、店舗情報の「宴会・貸切のご相談」（`/access/#party`。要点・席・貸切・よくある質問）に移した。入力欄も店舗情報ページへ移した。`/party/` はトップの `#party` へ301で転送

- 「経路を調べる」は template-parts ではなく関数 `akari_route_link()` で出している
- 下層ページの見出し部分を `template-parts/page-header.php` にまとめた
- 臨時休業の帯の終了日は「今日以降」しか保存できない（3.5の制約）。T-F12-1（終了日を昨日にする）は、当日の終了日で保存し翌日に消えることで確かめる
- お品書きの月替わりが0件のときは、詳細設計書U-10に合わせて「今月の月替わりは準備中です。」を出す（基本設計書3-9の「セクションごと出さない」とは異なる）
